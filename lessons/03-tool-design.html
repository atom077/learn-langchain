Lesson 03: 工具设计模式

模式 1: 复杂 Schema = 精确的参数控制

const searchProducts = tool(
  async ({ query, filters }) => { /* ... */ },
  {
    name: "search_products",
    description: "搜索产品。支持关键词、分类过滤、价格范围、库存过滤和排序。",
    schema: z.object({
      query: z.string().describe("搜索关键词"),
      filters: z.object({                          // ← 嵌套对象
        category: z.enum(["book", "electronics"])
                   .describe("产品分类").optional(),
        minPrice: z.number().min(0)
                   .describe("最低价格").optional(),
        maxPrice: z.number().min(0)
                   .describe("最高价格").optional(),
        inStockOnly: z.boolean()
                   .describe("只返回有库存").optional(),
        sortBy: z.enum(["price_asc", "price_desc"])
                   .describe("排序方式").optional(),
      }).describe("过滤选项").optional(),
    }),
  }
);
每个字段都用 .describe()——这不是注释，是给 LLM 看的参数说明书。Zod schema 被编译为 function calling 的 JSON Schema，LLM 据此决定如何填参数。

Schema 设计四要素

要素 Zod 写法 为什么重要
类型约束 z.string(), z.number() 防止 LLM 传错类型
值域约束 .enum([...]), .min(0) 限制可选值，防止 LLM 编造
可选性 .optional() 非必填字段用 optional，减少噪声
描述 .describe("...") LLM 的"参数说明书"，最关键

模式 2: 结构化错误 — 不要抛异常

// ❌ 不好的做法
if (balance < amount) throw new Error("余额不足");

// ✅ 好的做法：返回结构化错误对象
if (balance < amount) {
  return JSON.stringify({
    success: false,
    error: "INSUFFICIENT_BALANCE",         // 机器可读错误码
    message: `余额不足。当前: ¥${balance}，需要: ¥${amount}`,
    currentBalance: balance,                // 具体数据供 LLM 引用
    shortfall: amount - balance,            // 差额供 LLM 分析
  });
}
LLM 看到的是"数据"，不是"错误"。结构化错误对象给了 LLM 足够的数据来推理解决方案。

模式 3: 异步工具 — 调用外部世界

const getStockPrice = tool(
  async ({ symbol }) => {                    // ← async 工具
    const response = await fetch(            // ← 真实 API 调用
      `https://api.example.com/stock/${symbol}`
    );
    return JSON.stringify({ success: true, ...data });
  },
  { name: "get_stock_price", /* ... */ }
);

Agent 自动 await 异步工具，不需要手动管理 Promise。

工具描述的黄金法则

法则 ❌ 坏描述 ✅ 好描述
说明做什么 "调用 API 获取数据" "搜索产品。支持关键词、分类、价格范围"
说明何时用 "获取时间" "当用户问'现在几点'、'今天几号'时使用"
说明限制 "查询股票价格" "仅支持 AAPL, GOOGL, TSLA, MSFT"
对偶提示 "执行数学计算" "执行数学计算。涉及金额时必须用此工具验证"
