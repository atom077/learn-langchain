LangChain.js 是什么？

LangChain.js 是一个 Agent 工程平台，用于构建由大语言模型（LLM）驱动的应用。 它不是另一个 "prompt 包装器"——它的核心价值在于让 LLM 能够调用工具、访问外部数据、执行多步推理。

一句话总结：LangChain.js = 给 LLM 装上"手"和"脚"，让它不再是只会聊天的盒子，而是能干活、查数据、调用 API 的智能体。

它解决的核心问题

问题 没有 LangChain.js 有 LangChain.js
工具调用 手动解析 JSON、写 switch-case tool() 声明式定义，框架自动处理
对话记忆 手动管理消息数组、截断逻辑 内置 Memory 模块，多种策略即插即用
RAG（检索增强生成） 独立拼接 embedding + 向量搜索 + prompt 统一的 VectorStore 抽象 + 内置 RAG chain
多步推理 自己实现 ReAct/规划循环 createAgent() 开箱即用
可观测性 console.log 大法 LangSmith 追踪每一步推理

现代架构：Agent-First

从 2025 年起，LangChain.js 转向了 Agent-first 设计。核心 API 只有两个关键函数：

import { createAgent, tool } from "langchain";
import { z } from "zod";

// 1️⃣ 用 tool() 定义工具 — LLM 可以调用的函数
const getWeather = tool(
  ({ city }) => `It's always sunny in ${city}!`,
  {
    name: "get_weather",
    description: "获取指定城市的天气",
    schema: z.object({ city: z.string() }),
  }
);

// 2️⃣ 用 createAgent() 创建一个 Agent — 把 LLM + 工具组合在一起
const agent = createAgent({
  model: "anthropic:claude-sonnet-4-6",
  tools: [getWeather],
});

// 3️⃣ 调用！
const result = await agent.invoke({
  messages: [{ role: "user", content: "东京天气怎么样？" }],
});
关键洞察：整个架构围绕两个抽象旋转——createAgent（决策循环）和 tool（可调用的能力）。其他一切（memory、RAG、streaming）都是这两个抽象的增强。
