工具结构模板

const myTool = tool(
  async ({ param1, param2 }) => {
    // 永远返回 JSON.stringify({...})，不抛异常
    return JSON.stringify({ success: true, data: {...} });
  },
  {
    name: "my_tool",              // snake_case，动词_名词
    description: "做什么。何时用。有何限制。",
    schema: z.object({
      param1: z.string().describe("参数含义和格式"),
      param2: z.number().min(0).describe("参数含义和约束"),
    }),
  }
);

常见陷阱

  1. 忘记 optional — 非必填字段不加 .optional()，LLM 编造数据
  2. 抛异常而非返回错误 — 异常丢失上下文，LLM 无法推理
  3. 返回裸字符串而非 JSON — LLM 难以解析非结构化文本
  4. 描述太短 — "获取数据" 无法帮助 LLM 判断何时使用
  5. 工具粒度太粗 — 一个工具做三件事，LLM 难以准确调用
